# Food Wings

A modern and responsive food website built using **HTML, CSS, and JavaScript**. The project focuses on creating an attractive user interface, smooth interactions, and a responsive experience across desktop, tablet, and mobile devices.

## 🚀 Features

* 📱 Fully responsive design
* 🍔 Food/menu item showcase
* 🔍 Interactive user interface
* 🛒 Add-to-cart functionality
* ❤️ Favorite/wishlist interactions
* 📋 Dynamic menu sections
* 🎨 Modern and clean UI
* ⚡ JavaScript-powered interactions
* 📱 Mobile-friendly navigation
* ✨ Smooth hover and transition effects

## 🛠️ Technologies Used

* **HTML5** – Semantic structure and page content
* **CSS3** – Styling, responsive layouts, animations, and UI design
* **JavaScript (ES6+)** – Dynamic functionality and user interactions

## 💻 Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/your-username/food-website.git
```

### 2. Navigate to the Project

```bash
cd food-website
```

### 3. Run the Project

Open `index.html` directly in your browser.

For a better development experience, you can use **VS Code Live Server**.
